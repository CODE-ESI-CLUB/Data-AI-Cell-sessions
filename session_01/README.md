# 📊 Session 1: So, You Wanna Learn Data Science?

**By:** Salim EL MARDI  

## 🧠 Overview
This presentation introduces the fundamentals of **Data Science**, covering what data is, how it becomes information, and the key roles within the data ecosystem. It also gives a snapshot of **AI concepts**, their evolution, and real-world applications.

## 🔑 Key Highlights
- **What is Data?**  
  Raw facts (numbers, text, images) that gain meaning through analysis.  
  Types: structured (tables) and unstructured (tweets, photos).

- **Data vs Information**  
  Data = raw inputs → Information = processed insights.

- **Core Roles**  
  - *Data Scientist*: builds models and finds insights.  
  - *Data Engineer*: manages data pipelines.  
  - *Data Analyst*: visualizes and interprets data.  
  - *ML Engineer*: deploys AI models.

- **Applications**  
  Healthcare, finance, e-commerce, and transportation.

- **AI Overview**  
  AI learns and adapts from data, unlike static algorithms.  
  Includes milestones from early neural networks to today’s generative AI.

- **Learning Resources**  
  Platforms like Coursera, Fast.ai, DeepLearning.AI, and Kaggle for hands-on practice.
